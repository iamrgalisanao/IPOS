# Inventory Pilot Screenshot Capture Pack

Date: 2026-05-25
Scope: Slice F - Pilot Enablement Pack

## 1. Capture Rules

1. Use staging or training tenant and branch only.
2. Confirm no real customer or employee names are visible.
3. Hide browser bookmarks and unrelated tabs before capture.
4. Keep browser zoom at 100% and capture full viewport.
5. Do not edit numbers to misrepresent behavior; use realistic training data.

## 2. Required Screenshot Set

Capture in this order:

1. Inventory Hub landing page.
2. Inventory Hub card grouping with role-aware visibility.
3. Stocktake summary page in print-friendly layout.
4. Inventory report print-friendly page.
5. Low-stock and reorder dashboard filters.
6. Low-stock priority rows and advisory metrics.
7. Branch stock movement summary filter panel.
8. Movement summary type and source breakdown section.
9. Recent movement rows section.
10. Optional: no-data or permission-limited state for operator training.

## 3. File Naming Convention

Use this exact pattern:

1. `pilot-inventory-01-hub-landing.png`
2. `pilot-inventory-02-hub-cards.png`
3. `pilot-inventory-03-stocktake-print.png`
4. `pilot-inventory-04-report-print.png`
5. `pilot-inventory-05-low-stock-filters.png`
6. `pilot-inventory-06-low-stock-priority.png`
7. `pilot-inventory-07-movement-filters.png`
8. `pilot-inventory-08-movement-breakdown.png`
9. `pilot-inventory-09-movement-recent-rows.png`
10. `pilot-inventory-10-permission-state.png`

## 4. Storage Path

Store files in:

1. `docs/user-enablement/assets/pilot-inventory/`

## 5. Caption Template

For every screenshot, provide:

1. Screen name.
2. Intended actor role.
3. Action being demonstrated.
4. Expected success signal.
5. Boundary note (if relevant).

## 6. Quality Gate Checklist

Before publishing screenshot assets:

1. All text labels are legible.
2. Branch context is visible where expected.
3. No sensitive values or identities appear.
4. Date or run context is consistent across sequence.
5. Screens map to currently implemented UI only.
