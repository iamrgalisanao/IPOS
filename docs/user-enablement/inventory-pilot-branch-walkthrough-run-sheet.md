## 2. Mandatory Opening (1-2 minutes)

1. State this is a pilot-ready inventory walkthrough.
2. Confirm training-safe, non-production data.
3. Confirm no certification/accreditation claims.

## 3. Walkthrough Sequence (Use In Order)

1. Inventory Hub orientation.
2. Print-friendly stocktake/inventory report views.
3. Low-stock and reorder advisory dashboard.
4. Branch stock movement summary filters and breakdowns.
5. Quick recap of read-only boundaries.

## 4. Timebox Guide

1. Opening and boundary statements: 2 minutes.
2. Hub and report pass: 8 minutes.
3. Low-stock and movement summary pass: 10 minutes.
4. Q and A plus checklist sign-off: 8 to 10 minutes.

## 5. Facilitator Prompts

1. "Can you locate this surface from the hub without assistance?"
2. "What operational decision would you make from this dashboard?"
3. "What part of this flow needs clearer labels or examples?"
4. "Did any step feel risky or unclear for branch operations?"

## 6. Real-Time Checks

Mark each as Done/Not Done during the session:

1. Boundary disclaimer stated.
2. All four key surfaces shown.
3. No unsupported feature promises made.
4. No sensitive data exposed.
5. Post-demo checklist completed.

## 7. Escalation Trigger Shortlist

Escalate immediately if:

1. A required screen is inaccessible for expected role.
2. Potential non-training data appears.
3. Messaging risks prohibited compliance claims.
4. Script does not match current UI behavior.

2. Confirm sign-off entries in checklist addendum.
