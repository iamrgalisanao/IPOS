# Inventory Pilot Checklist Addendum

Date: 2026-05-25
Scope: Slice F - Pilot Enablement Pack

## 1. Pre-Demo Checklist

1. Confirm training/staging tenant and branch selection.
2. Confirm demo account permissions match intended audience role.
3. Confirm screenshot sequence files are complete and current.
4. Confirm no production identities are present in demo dataset.
5. Confirm all referenced pages load without permission errors.

## 2. Live Demo Checklist

1. Start with boundary disclaimer and pilot-ready positioning.
2. Walk through Inventory Hub first.
3. Show print-friendly report surfaces.
4. Show low-stock advisory dashboard.
5. Show movement summary filters and recent rows.
6. Avoid unsupported claims and mutation promises.

## 3. Post-Demo Checklist

1. Collect questions, confusion points, and requested clarifications.
2. Record role-specific pain points for next enablement revision.
3. Archive the demo version used (date + branch context).
4. Log any mismatch between script and current UI.
5. Raise follow-up items to Product Operations and Engineering owners.
