# Inventory Pilot Branch Manager Demo Script

Date: 2026-05-25
Audience: Branch managers and pilot stakeholders
Duration: 20 to 30 minutes

## 1. Opening Script

1. Introduce scope: this is a pilot-ready inventory operations walkthrough.
2. Clarify boundary: no claims of BIR certification or accreditation.
3. Clarify data source: training-safe, non-production dataset.

## 2. Demo Flow

### Step 1: Inventory Hub Orientation

1. Open Inventory Hub.
2. Explain grouped access to stock visibility, stocktake, reports, and movement
   views.
3. Highlight role-aware card visibility and read-only posture.

### Step 2: Print-Friendly Stocktake and Inventory Reports

1. Open stocktake report print-friendly surface.
2. Explain binder-ready formatting for branch operations and audit filing.
3. Show inventory report print-friendly layout.

### Step 3: Low-Stock and Reorder Read-Only Dashboard

1. Apply category and priority filters.
2. Explain low-stock and negative-stock signals.
3. Explain advisory-only reorder visibility and no auto-PO behavior.

### Step 4: Branch Stock Movement Summary

1. Apply movement type and source filters.
2. Explain type and source breakdown totals.
3. Review recent movement entries for troubleshooting context.
4. Reinforce read-only and append-only movement visibility boundary.

## 3. Key Talking Points

1. Pilot value: better operational visibility and training clarity.
2. Boundary value: no mutation automation introduced in this track.
3. Governance value: all slices executed under explicit non-goal controls.

## 4. Demo Success Criteria

1. Audience can locate all four operational surfaces.
2. Audience can explain low-stock versus movement summary use-cases.
3. Audience understands read-only limitations and escalation path.
4. No prohibited claim language used during the walkthrough.

## 5. Closing Script

1. Summarize capabilities delivered in priorities 1 to 5.
2. Confirm next step is branch onboarding packet handoff.
3. Capture feedback and unclear steps for guide refinement.
