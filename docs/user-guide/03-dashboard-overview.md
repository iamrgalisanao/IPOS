# 03. Dashboard Overview

Status: Validated  
Last Updated: 2026-05-30  
System Area: Back Office Dashboard  
User Roles: Owner/Admin, Branch Manager, Accountant

---

## 1. Purpose

The Dashboard is the operational control center of IPOS. It provides real-time transaction pulses, sales KPI trends, and settlement locking statuses without requiring users to compile complex spreadsheet reviews.

---

## 2. Who Can Access the Dashboard

* **Owner / Admin**: Accesses the global **Tenant-Wide Pulse Dashboard** (aggregated views of all branches, payment mixes, and branch sales rankings).
* **Branch Manager**: Accesses the **Branch-Scoped Dashboard** (filtered automatically to display only the metrics of their assigned branch).
* **Accountant**: Accesses the Dashboard to monitor integration statuses and latest locked settlement cards.

---

## 3. Screen Overview

The Dashboard consists of four main sections:

### A. Real-Time Sales KPIs
* **Gross Sales**: Sum of all sales recorded today.
* **Net Sales**: Gross sales minus discounts and refunds.
* **Transaction Count**: Total checked-out invoices.
* **Average Basket Value**: Average revenue generated per invoice.

### B. Payment Mix Distribution
A visual breakdown comparing cash collections vs. digital payment methods (GCash, credit card, e-wallets). This helps managers plan bank drops and reconcile physical drawer counts.

### C. Branch Comparison Chart (Admins Only)
A ranking comparison bar chart showing gross revenue generated by each active store location.

### D. Latest Locked Settlement Card
Displays the date and summary of the most recently finalized daily settlement period, confirming that the accounting books are locked up to that date.

---

## 4. Mobile Responsive Optimization

The entire back office dashboard is fully responsive. When accessed on mobile devices or tablets:
* The side navigation menu collapses into a touch-friendly hamburger menu.
* Dashboard metrics stack vertically for easy scrolling.
* Charts adapt to screen width dynamically.
